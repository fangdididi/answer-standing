# 完整示例（虚构）：给一位独立作者做“AI 怎么介绍我”的体检

以下人名、书名和数字都是为了演示而虚构的。

## 情况

作者“林知远”出版了两本科普书。读者告诉她：问 AI“林知远是谁”，AI 会说她是一位“经济学教授”，还把另一位同名作家的小说算到她头上。

## 事实底表（节选）

```yaml
product:
  name: "林知远"
  not_to_be_confused_with: ["同名小说作者林知远（另一人）"]
facts:
  what_it_is: { value: "科普作者，前中学物理老师", as_of: "2026-10-01", public_url: "https://example.com/about" }
  books:      { value: "《厨房里的物理》2023；《雨是怎么落下来的》2025", as_of: "2026-10-01", public_url: none }
```

`books` 没有任何公开的完整书目页：这本身就是一个发现。

## 题库（核心 8 题，节选）

| 题号 | 类别 | 原话 |
| --- | --- | --- |
| Q01 | 直问题 | 林知远是谁？ |
| Q02 | 直问题 | 林知远写过哪些书？ |
| Q05 | 品类题 | 适合初中生的物理科普书推荐 |
| Q07 | 问题题 | 怎么跟孩子解释为什么会下雨？ |

## 采样与判定

在两个国内助手上各采 3 次，共 48 条回答。说法判定结果：

- “经济学教授”：**conflated 混淆**，来源追溯到一个百科类页面把两个同名者合在了一起。
- “代表作是长篇小说《……》”：**conflated 混淆**，同上。
- “《厨房里的物理》适合 10 岁以上读者”：**correct 正确**，来源是出版社页面。
- “她在高校任教”：**invented 编造**，没找到任何来源；因为她的公开简介里从没写过职业经历。

## 修正计划

1. 在个人网站上写一页朴素的“关于我”：职业经历、两本书的书名和出版年份、以及一句“我与同名小说作者不是同一人”。
2. 通过百科类页面的正规纠错渠道提交更正，附上出版社页面作为证据。
3. 让出版社的作者简介与个人网站说法一致。
4. 对 Q07 这类“问题题”，在个人网站上写一篇真正有用的短文，用书里的实验步骤回答，而不是写广告。

## 复测

八周后用同样的 8 题、同样的助手、同样每题 3 次复测，把前后两份 `answers.csv` 交给 `standing.py compare`。报告只写检验支持的结论：混淆类说法是否减少，提及率变化是真实的还是噪声。
